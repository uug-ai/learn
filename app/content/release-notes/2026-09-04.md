Expanded audit visibility, improved project-aware recording access, and stronger workflow and retention reliability.

<!--more-->

## Audit history

- Added a full audit history interface with search, date ranges, categories, outcomes, permissions, and actor filters.
- Added grouped event views, expandable details, pagination, loading states, and responsive layouts.
- Added audit events for task updates, including field and status changes.
- Improved compatibility with historical audit events so older records appear consistently alongside new activity.

## Projects and recording access

- Added project-based storage and Agent credential resolution for multi-project deployments.
- Improved available recording date discovery with project- and device-specific results, deduplication, and compatibility fallbacks.
- Improved workflow and workflow-run project scoping while preserving access to existing resources that predate project ownership.

## Workflow reliability

- Added stricter Vault configuration resolution that accepts one unambiguous configuration and reports conflicting site mappings clearly.
- Improved error reporting and retry handling when workflow runs are created or stages are dispatched.
- Prevented storage and dispatch failures from being hidden by automatic fallbacks.

## Retention and cleanup

- Added independently configurable retention for audit history.
- Strengthened organisation-aware cleanup across recordings, workflow runs, analysis, notifications, heatmaps, counting, and sequences.
- Improved timestamp fallback handling and task cleanup safeguards to avoid deleting related data when retention eligibility changes during processing.

## Live monitoring

- Changed live view to load additional streams continuously instead of applying a fixed stream limit by default.
- Reduced development tooling overhead from high-frequency live actions.
