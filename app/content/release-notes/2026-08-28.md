Advanced organisation and project support, stronger live-stream and marker isolation, and more reliable workflow processing under load.

<!--more-->

## Organisations and projects

- Redesigned the organisation and project switcher with unified context menus, search, resizing, accessibility improvements, and project management actions.
- Added broader configuration support for organisation and project features across runtime environments.
- Added project-aware workflow, Vault, and workflow-run filtering with compatibility for existing resources.
- Improved ownership resolution throughout retention processing so organisation data remains correctly isolated.

## Maps, redaction, and remote recording

- Added configurable map overlay layers with controls for credentials, attribution, zoom levels, and opacity.
- Added support for using classifier-generated tracks in face-redaction workflows.
- Added configuration support for remote recording capabilities.

## Live streaming and markers

- Improved HLS isolation by scoping playlists, segments, and live-edge tracking to the device and viewing session.
- Added access to recent device markers with bounded pagination.
- Strengthened marker ownership validation and application access controls.

## Workflow reliability

- Added atomic workflow dispatch and finalisation safeguards to prevent duplicate work during concurrent processing.
- Improved workflow completion checks, timeout handling, and failure recovery.
- Changed transient recording persistence failures to retry rather than allowing data to be skipped.
- Improved marker linking performance and consistency when recordings and markers arrive at different times.

## Trusted device processing

- Added stricter validation of source device identity and ownership as recordings move through the processing pipeline.
- Preserved source device and project identity throughout event processing.
- Improved trace continuity across Vault and pipeline processing for more reliable operational diagnostics.
