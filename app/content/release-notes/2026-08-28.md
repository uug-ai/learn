## Historical recordings and analytics

- Added historical recordings directly to live view with timeline playback, scrubbing, zoom, playhead controls, sprite thumbnails, and marker activity.
- Improved timeline scaling, ruler interactions, hover behavior, and portrait recording presentation.
- Added a device analytics view with recording upload and gap metrics, including loading feedback.

## Maps and remote recording

- Added optional map overlay layers with deployment-level configuration for credentials, attribution, zoom limits, and opacity.
- Added remotely initiated recording controls and enabled the capability by default.

## Projects and resource isolation

- Refined project navigation by nesting project features under organisations and previewing available projects before switching.
- Added project-aware workflow, Vault, and workflow-run filtering while preserving access to existing resources.
- Strengthened project ownership checks for media, analytics, cases, devices, markers, notifications, and related resources.
- Improved HLS isolation by scoping playlists, segments, and live-edge tracking to the device and viewing session.
- Added access to recent device markers with bounded pagination.

## Workflow and notification reliability

- Added atomic workflow dispatch and finalisation safeguards to prevent duplicate work during concurrent processing.
- Improved workflow completion checks, timeout handling, and failure recovery.
- Changed transient recording persistence failures to retry rather than allowing data to be skipped.
- Improved marker linking performance and consistency when recordings and markers arrive at different times.
- Added atomic notification delivery claims and improved project-aware alert evaluation.

## Trusted device processing

- Added stricter validation of source device identity and ownership as recordings move through the processing pipeline.
- Preserved source device and project identity throughout event processing.
- Improved trace continuity across Vault and pipeline processing for more reliable operational diagnostics.
