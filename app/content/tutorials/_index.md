Step-by-step walkthroughs to get hands-on with the Kerberos.io ecosystem. Each tutorial focuses on one product and guides you from zero to a working setup.

## Available tutorials

- [Agent](agent/) — install and run an Agent on your machine of choice.
- [Vault](vault/) — deploy and configure Vault for storage and forwarding *(coming soon)*.
- [Hub](hub/) — set up your own workflow stage and integrate a custom service into the pipeline, end to end.

## Structure

Tutorials are grouped per product. Inside each product folder you'll find one or more focused walkthroughs (e.g. `install`, `upgrade`, `integrate`). New tutorials can be added by creating a new folder under the relevant product with an `index.md` (or `_index.md` for a section).
