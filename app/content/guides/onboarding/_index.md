Joining a new company involves a significant learning curve. This guide covers key aspects of onboarding, including meeting your colleagues, understanding company culture and processes, and establishing yourself within the team. 

It takes a while before you become productive and contribute to one of the projects you are working on. To simplify this process, companies have some kind of automation tools to get you up and running quickly. It all depends on the ecosystem the company is working with: Google, Apple, Microsoft, etc. 

Within Augment Vision we are working with the Apple and Google stack, which means you will have a dedicated `@uug.ai` email and Google Workspace to arrange meetings, store files, and much more, and you will have dedicated Apple equipment like a MacBook, iPhone, AirPods, etc.

## Developer Setup

At Augment Vision, we streamline onboarding through a two-phase provisioning process:

1. **[Dev Machine](/guides/onboarding/dev-machine)**: Configure your local development environment with the required tools and dependencies.
2. **[Dev Container](/guides/onboarding/dev-containers)**: Use the preconfigured container locally or as the basis of a GitHub Codespace.

This approach ensures you can contribute effectively to our projects quickly while maintaining consistency across the team.

## Supportive tooling

At Augment Vision, we use a suite of integrated tools to streamline code sharing, deployment monitoring, and team collaboration:

- **Version Control**: GitHub for code management, collaboration, and pull request reviews
- **CI/CD Pipeline**: GitHub Actions for automated testing and deployment, with GitOps/Argo CD managing production deployments
- **Communication**: Slack for team messaging and community engagement
- **Project Management**: GitHub Projects for tracking issues, pull requests, and development progress
- **Documentation**: Centralised knowledge base at learn.uug.ai with documentation replicated across local repositories for easy access
